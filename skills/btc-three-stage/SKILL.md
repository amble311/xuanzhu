# 三周期打分 + 1 小时线择时

判断任何开仓 / 加仓 / 平仓时机，都先看三周期打分，再用 1 小时线定时。
工具：`btc_signal`（一次给出全部结论）。

## 核心规则（用户设定）

| 三周期（周 / 日 / 4h） | `side_filter` | 允许的操作 |
|---|---|---|
| 都 ≥0，且至少一个 +1 | `long` | **只做多** |
| 都 ≤0，且至少一个 -1 | `short` | **只做空** |
| 全为 0 | `none` | 不做 |
| 有正有负（冲突） | `none` | 不做 |
| 任一周期数据不足 | `unknown` | 不做（先补数据） |

- 每个周期：`+1` 上涨势、`0` 横盘/中性、`-1` 下跌势。
- 有横盘周期参与时仓位减半（`position_hint` 会给）；三周期都非 0 才是标准仓。
- **1 小时线负责「有没有机会」**：它在 1h 上做技术分析（结构 / 位置 / 动量 / 量能 / 形态），
  给出 0–100 的机会评分与形态（回调 `pullback` 或放量突破 `breakout`）；
  `score ≥ 60` 且结构、位置、形态都不为 0 才是 `entry=now`，否则 `wait`（等回调/突破）。
- 1h **不能把三周期给出的方向翻过来** —— 它只能不给入场许可。

## 输出怎么读

| 字段 | 含义 |
|---|---|
| `score.weekly` / `score.daily` / `score.h4` | 各周期打分（-1 / 0 / +1），`null` = 数据不足 |
| `side_filter` | `long` / `short` / `none` / `unknown`（方向结论） |
| `side_reason` | 为什么是这个结论（含缺什么数据） |
| `action` | `long` / `short` / `wait` / `stand_aside` |
| `position_hint` | 仓位建议（1.0x / 0.5x / 0） |
| `stage4_1h.entry` | `now` / `wait`：1 小时线是否给出机会 |
| `stage4_1h.score` | 0–100 机会评分；`score_breakdown` 给五项得分 |
| `stage4_1h.opportunity` | `pullback`（回调到 MA20 附近）/ `breakout`（放量突破前 48 根极值）/ `none` |
| `stage4_1h.trend` | 1h 自身趋势：`up` / `down` / `flat` |
| `stage4_1h.levels` | 最近的支撑 / 阻力（MA20、MA50、48 根极值） |
| `stage4_1h.invalidation` | 这次机会的失效条件（止损价 / RSI 阈值） |
| `stage4_1h.degraded` | `true` = 1h 数据不足，**结论必须写「1 小时线未确认，不做」** |
| `stage4_1h.stop` / `targets` | 止损与 2R / 3R（工具已算，不要自己编） |
| `confidence` | 三周期置信度最小值；`< 0.5` 时仓位再减半 |

阈值与判定细则见同目录 `references/stage-rules.md`（`load_skill` 返回里有绝对路径）。

## 报结论的格式

1. 一句话方向：做多 / 做空 / 等 / 不做，以及为什么（哪一周期否决的）；
2. 三周期各一行：打分 + 关键数字（周线均线排列/ADX、日线 RSI/MACD、4h 均线排列）；
3. 1 小时线：机会评分（哪几项得分/失分）+ 形态（回调/突破）+ 关键支撑阻力 +
   入场区间、止损、2R/3R、失效条件；
4. 数据口径：`as_of` 时间 + 是否 `degraded`。

评分低但结构没坏时，要说明「等什么」：等回踩 MA20、等放量突破前高、等 RSI 回到 40 上方。

## 反例（不要做）

- 三周期里有一个反向还硬给方向（`side_filter=none` 就是不做）；
- 用 1 小时线「确认」出一个三周期没给的方向；
- 明明 `stage4_1h.entry=wait`（评分不足或没有形态），却说「可以先进一部分」；
- 只看 4 条指标打勾就进，不看评分、形态与失效条件；
- 1h 数据缺失时用日线信号声称「1 小时线已确认」；
- 忽略 `btc_order` 的方向闸门：被拒后改口说「先挂上」。
