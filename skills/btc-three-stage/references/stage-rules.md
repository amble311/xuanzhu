# 三阶段判定细则

本文件是 `btc_signal` 内部判定条件的可读版本。**数字以工具返回为准**，
这里只用于解释「为什么是 bull / wait / stand_aside」，不要拿它替代工具输出。

## 第一阶段：周线定势

由本地日线重采样成周线（`W-FRI`，标签取周起始日），指标与日线同一套。

| 判定 | 条件（周线） | 含义 |
|---|---|---|
| `bull` 上涨势 | 收盘 > MA20W > MA50W，MA20W 斜率 > +0.1%/周，ADX ≥ 18 | 只做多，回调买入 |
| `bear` 下跌势 | 收盘 < MA20W < MA50W，MA20W 斜率 < -0.1%/周，ADX ≥ 18 | 只做空，反弹卖出 |
| `range` 震荡市 | 以上都不满足（ADX < 18 或均线缠绕） | 只做区间边缘反转，半仓 |

- `confidence` < 0.5 时把仓位减半。
- 记下 `range.hi20` / `range.lo20`：这是日线判断区间位置的锚。

## 第二阶段：日线定方向

**周线 bull（做多窗口）**，满足 ≥3 条才给 `long`：

- 收盘 > MA50D（中期趋势未破）
- RSI 38–68（回调后不超买）
- MACD 柱 > 0 或连续放大
- 贴近 MA20D（±4%）或日线区间位置 ≤ 62%

**周线 bear（做空窗口）**，满足 ≥3 条才给 `short`：

- 收盘 < MA50D
- RSI 32–62
- MACD 柱 < 0 或连续走弱
- 贴近 MA20D（±4%）或区间位置 ≥ 38%

**周线 range**：

- 位置 ≤ 22% 且 RSI < 38 → `long`（区间下沿反转，半仓）
- 位置 ≥ 78% 且 RSI > 62 → `short`（上沿反转，半仓）
- 其余 → `wait`

任何情况下，日线与周线方向相反 → 一律 `wait`（不做逆势）。

## 第三阶段：小时线定时

**做多触发（≥3 条且站上 MA20H）**：

- 收盘 > MA20H
- MA20H > MA50H
- RSI 45–72（不追超买）
- MACD 柱 > 0

**做空触发（≥3 条且跌破 MA20H）**：

- 收盘 < MA20H
- MA20H < MA50H
- RSI 28–55
- MACD 柱 < 0

入场与风控（工具已算）：

- 入场区间：`entry_zone`（回踩 MA20H 附近，不追高）
- 止损：多 = 最近 24 根低点 − 0.5×ATR；空 = 最近 24 根高点 + 0.5×ATR
- 目标：2R / 3R（`targets`）
- 仓位：按止损距离算，单笔风险 ≤ 账户权益 2%；标准仓 1.0x，震荡市半仓

## 小时线缺失时

`stage3_hourly.degraded = true`（来源为 `unavailable: ...`）：

- 不要假装有小时信号；只能做日线级判断并**明确写出「缺 1h 数据」**；
- 先 `btc_sync timeframe=1h` 补齐，再重新调 `btc_signal`；
- 补齐后 `confidence` 会恢复，此前给出的结论要标注为「数据不全时的旧结论」。

## 平仓逻辑（供参考，当前模式尚未接入下单工具）

- 止损位被日线收盘击穿 → 平仓，当日不再入场；
- 周线趋势由 `bull` 转 `range` / `bear` 且日线跌破 MA50D → 减仓或平仓；
- 到达 2R 先减半，剩余用 3R 或移动止损（前一根日线低点）。
