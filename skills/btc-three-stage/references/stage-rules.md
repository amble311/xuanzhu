# 三周期打分细则

本文件是 `btc_signal` 内部判定条件的可读版本。**数字以工具返回为准**，
这里只解释「为什么是 +1 / 0 / -1」，不要拿它替代工具输出。

## 周期口径

| 周期 | 来源 | 用途 |
|---|---|---|
| 周线 | 本地日线重采样（`W-FRI`，标签取周起始日） | 判势 |
| 日线 | 本地 `1d`（≥60 根） | 判势 |
| 4 小时线 | 本地 `1h` 重采样（`o=first / h=max / l=min / c=last / v=sum`） | 判势 |
| 1 小时线 | 本地 `1h`（≥120 根） | **只做入场择时** |

4h 与 1h 都来自同一份 1h 数据 —— 这是刻意的：多同步一个周期就多一份要维护、
要对齐、要补的数据，而聚合结果完全确定。

## 打分：`+1` 上涨势 / `0` 横盘 / `-1` 下跌势

### 周线（`stage1_weekly.score`）

| 判定 | 条件 | 分 |
|---|---|---|
| `bull` | 收盘 > MA20W > MA50W，MA20W 斜率 > +0.1%/周，ADX ≥ 18 | +1 |
| `bear` | 收盘 < MA20W < MA50W，MA20W 斜率 < -0.1%/周，ADX ≥ 18 | -1 |
| `range` | 其余（ADX < 18 或均线缠绕） | 0 |

### 日线（`stage2_daily.score`）

**独立判断**，不再依赖周线结论（旧版由周线决定检查哪一组条件）：

做多检查（≥3 条且多于做空条件 → `+1`）：

- 收盘 > MA50D
- RSI 38–68
- MACD 柱 > 0 或转强
- 贴近 MA20D（±4%）或日线区间位置 ≤ 62%

做空检查（≥3 条且多于做多条件 → `-1`）：

- 收盘 < MA50D
- RSI 32–62
- MACD 柱 < 0 或走弱
- 贴近 MA20D（±4%）或区间位置 ≥ 38%

边缘反转（不满足上面任一组时）：位置 ≤ 22% 且 RSI < 38 → `+1`；
位置 ≥ 78% 且 RSI > 62 → `-1`。其余 → `0`。

### 4 小时线（`stage3_4h.score`）

| 条件 | 分 |
|---|---|
| 收盘 > MA20(4h) > MA50(4h) 且 ADX(4h) ≥ 18 | +1 |
| 收盘 < MA20(4h) < MA50(4h) 且 ADX(4h) ≥ 18 | -1 |
| 其余（均线缠绕 / ADX 不足 / 数据不足） | 0 |

ADX 门槛与周线一致：没有强度确认时，横盘里价格贴着均线上方一点也会算「上涨势」，方向会放得太松。

4h 只判势，**不再充当入场扳机**（旧版 `stage3_4h.entry` 已移到 `stage4_1h`）。

## 合成为方向（`side_filter`）

按顺序判断，先命中先返回：

1. 任一周期 `score = null` → `unknown`（数据不足，不做）；
2. 三个都是 0 → `none`（全横盘，不做）；
3. 都 ≥0 且至少一个 +1 → `long`（只做多）；
4. 都 ≤0 且至少一个 -1 → `short`（只做空）；
5. 其余（有正有负）→ `none`（冲突，不做）。

## 1 小时线机会评估（`stage4_1h`）

**分工**：三周期只决定「允许做多 / 做空」；1h 决定「现在有没有值得进的机会」。

三周期不同向时返回 `entry=wait, source=skipped`，不做额外计算。

### 评分（0–100）

| 项 | 满分 | 取值 |
|---|---|---|
| 结构 | 30 | 价格在 MA50 上方且 MA20 ≥ MA50 → 30；在 MA50 上方但均线缠绕 → 15；在 MA50 下方 → 0（做空对称）。**短期跌破 MA20 视为回调，不算趋势反转** |
| 位置 | 20 | 回调到 MA20(1h) 附近（±1 ATR）20；区间中部 12 / 6；追高（多单贴近 48 根高点）或追空 0 |
| 动量 | 20 | MACD 柱方向一致 10；且比前一根更强 再 +10 |
| 量能 | 15 | `vol_ratio ≥ 1.2` 15；`≥ 0.8` 8；否则 0 |
| 形态 | 15 | 回调入场或放量突破前 48 根极值 |

**`entry = now` 需要同时满足：`score ≥ 60`、结构 > 0、位置 > 0、形态 > 0。**
结构或形态为 0 一律 `wait` —— 指标都对但 1h 没趋势/没形态，不算机会。

### 形态（`opportunity`）

| 形态 | 做多条件 | 做空条件 |
|---|---|---|
| `pullback` 回调 | 价格在 MA20(1h) ±1 ATR 内，结构未坏，RSI ≥ 40（横盘时还要求 RSI 回升且 ≥45） | 对称：±1 ATR 内，RSI ≤ 60（横盘时要求回落且 ≤55） |
| `breakout` 突破 | 收盘 > 前 48 根高点，`vol_ratio ≥ 1.2`，RSI 40–78 | 收盘 < 前 48 根低点，`vol_ratio ≥ 1.2`，RSI 22–60 |
| `none` | 以上都不成立 → `wait` | 同 |

「前 48 根」**不含当前根**（用当前 K 线自己当参照会自证成立）。

### 输出与风控（工具已算，不要自己编）

- `levels`：最近的支撑 / 阻力（MA20、MA50、48 根极值）；
- `invalidation`：这次机会的失效条件（止损价 + RSI 阈值）——机会作废就该重新评估，不是死扛；
- `entry_zone`：回踩/反弹到 MA20(1h) 附近的挂单区间；
- 止损：多 = 最近 24 根 1h 低点 − 0.5×ATR；空 = 最近 24 根 1h 高点 + 0.5×ATR；
- 目标：2R / 3R（`targets`）；
- 仓位：`position_hint`；含横盘周期减半，`confidence < 0.5` 再减半；
- `snapshot`：1h 原始指标（MA/RSI/MACD/ATR/vol_ratio/区间位置），供你补充判断 ——
  可以比它**更保守**（放弃机会），但不能据此翻方向。

## 数据不足时

- `stage3_4h.degraded = true`（4h 不可用，通常是本地 1h < 480 根）→ `side_filter = unknown`，不做；
- `stage4_1h.degraded = true`（1h < 120 根）→ `action = wait`，**不要**退回日线级入场；
- 先把 `btc_sync timeframe=1h` 补齐，再重新调 `btc_signal`；旧结论要标注「数据不全」。

## 方向闸门（硬性）

`btc_order` 在发请求前会再算一次同样的结论（60 秒缓存）：

- `side_filter` 与下单方向不符 → **拒绝**（真钱）；
- `none` / `unknown` → 同样拒绝；
- 模拟盘 `btc_paper_open` 不拦，但会在返回里标注「实盘会被拒绝」。

被拒后不要换说法绕过，也不要建议用户「手动挂上就行」—— 要说清是哪一周期否决的。

## 平仓逻辑（供参考）

- 止损位被收盘价击穿 → 平仓，当日不再入场；
- 周线由 `bull` 转 `range` / `bear` 且日线跌破 MA50D → 减仓或平仓；
- 到达 2R 先减半，剩余用 3R 或移动止损（前一根日线低点）。
